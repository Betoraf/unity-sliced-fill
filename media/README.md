# Cover

`sliced-fill-cover-1920x1080.png` is the release cover, 1920 × 1080 pixels.

The visual uses blumgames' rounded wordmark style, a quiet dark background and one green product illustration. The partial bars show a straight crop rather than a compressed end cap.

Cover created with image generation, using the author's supplied watermark as the brand reference. Design direction was refined with [unslop by Damir Sokolovsky (@heydamir)](https://github.com/heydamir/unslop), whose skill is licensed under CC BY 4.0. The skill itself is not bundled with this package.
